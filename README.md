# MarkSix

六合彩风格「琼花开奖器」：**农历干支取数 → 起卦（本卦 / 互卦 / 变卦）→ 七个卦数映射到号码同余类 → 类内随机取号 → 逐球滚动开奖**。

单文件 HTML，BGM、图标、音效全部内联，断网也能跑。

## 特性

- **号码结构**：`CFG.NORMAL = 6` 个正码 + 1 个特码，号码范围 `1 ~ 49`，按卦位顺序落球、不排序。
- **波色**：红波 17 个、蓝波 16 个、绿波 16 个，按六合彩标准分色（`RED` / `BLUE` 两个 Set，其余归绿）。
- **生肖**：`zodiac(n) = ZOD[(yi − (n − 1)) mod 12]`，基准 `yi` 由当前年份推出，跨年自动换表。
- **开奖动画**：每球先 40 帧快滚（250 ms/帧），再 5 帧减速（120 → 340 ms），落定后爆粒子；球与球之间间隔 250 ms，整期约 80 秒。
- **不重复**：滚动序列在生成阶段就排除「已开出的号码」和「本球最终号码」，不会闪回已知数字。
- **音效**：全部 Web Audio 实时合成 —— 滚动时的 880–1080 Hz 正弦短音、落球的 C 大调四音琶音、特码升八度的五音琶音，零音频文件依赖。
- **BGM**：base64 内联 MP3 循环播放，首次点击后才启动（绕开自动播放限制），并用增益 `1e-5` 的静音振荡器保活 `AudioContext`。
- **历史**：`localStorage['lucky_history']`，最多保留 20 期，带 `M/D HH:mm` 时间戳，可一键清空。
- **今日卡**：公历 + 农历双显示；「今时幸运号码」每两小时（一个时辰）自动刷新。
- **离线可用**：唯一外链是 Google Fonts 的「马善政」毛笔字体，断网时回退系统字体，功能不受影响。

## 算法原理

### 1. 时间基准

`bjTime()` 返回 `new Date(Date.now() + 28800000)`，即把时间平移 8 小时后统一用 `getUTC*` 读取 —— 无论系统时区在哪，取到的都是北京时间。

### 2. 农历与干支

`toLunar()` 用 1900–2100 年的 `LUNAR` 压缩表（每年一个整数：低 4 位存闰月月份、`0x10000` 位存闰月大小、其余 12 位存每月大小），从 `1900-01-31` 起按天数差逐月扣减，得到 `{ y, m, d, isLeap }`。

两个派生量：

```text
年支序号  yz = ((lunar.y − 4) mod 12) + 1     鼠 = 1 … 午 = 7 … 猪 = 12
时辰序号  sc = ⌊((hour + 1) mod 24) / 2⌋ + 1  子 = 1 … 亥 = 12（每两小时一位）
```

2026 年是丙午年，`yz = 7`。

### 3. 起卦

三个输入（年支、农历月、农历日）加一个固定偏移 16，推出本卦与动爻：

```text
base = yz + lunar.m + lunar.d + 16
上卦 u = base mod 8          （结果为 0 时记作 8）
下卦 l = (base + sc) mod 8   （同上）
动爻 m = (base + sc) mod 6   （结果为 0 时记作 6）
```

`base` 只随农历日变化，所以**上卦在一整个农历日里固定不变**，下卦与动爻则随时辰每两小时前进一位 —— 这正是「今时幸运号码」需要按奇数点重绘（`scheduleNextShichen`）的原因。

### 4. 八卦编码

用先天八卦的三位二进制表示，`GY` 是「卦数 → 爻」正表，`y2g` 反解（`8 − 二进制值`）：

| 卦数 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| 卦 | 乾 | 兑 | 离 | 震 | 巽 | 坎 | 艮 | 坤 |
| 爻（自下而上） | 111 | 110 | 101 | 100 | 011 | 010 | 001 | 000 |

### 5. 互卦与变卦

六爻排布 `six = 下卦三位 + 上卦三位`（`six[0]` 为初爻、`six[5]` 为上爻）：

- **互卦**：下互取 2·3·4 爻 → `hl = y2g(six[1..3])`；上互取 3·4·5 爻 → `hu = y2g(six[2..4])`
- **变卦**：动爻 `m` 翻转（0↔1）得到 `six2`，再按 1–3 / 4–6 爻拆回下卦 `bl`、上卦 `bu`

于是得到七个卦数 `[u, l, m, hu, hl, bu, bl]`：上卦、下卦、动爻、上互、下互、上变、下变。

### 6. 卦数 → 号码

七个卦数依次对应七个号位（前六个正码、第七个特码）。每个卦数 `g` 展开成一个步长为 8 的同余类：

```text
C(g) = { g, g + 8, g + 16, … , ≤ 49 }
```

- 类 1 = `{1, 9, 17, 25, 33, 41, 49}` 共 7 个，其余各类 6 个
- 在每个类里剔除本期已用号码后，用 `Math.random()` 均匀抽一个
- 七个卦数经常重复（下例中 4 出现两次、8 出现三次），重复就从同一类继续抽未用号，保证整期 7 个号码互异

注意：**卦数决定骨架、随机决定成员**。整期的七个同余类完全由日期与时辰决定，只有「类里挑哪一个」是随机的。

### 7. 生肖与波色

- 生肖：`yi` 由公历年推出（2026 → 马 = 6），`zodiac(n) = ZOD[(yi − (n − 1)) mod 12]`，即 1/13/25/37/49 对应当年生肖，2/14/26/38 对应下一个，依此类推
- 波色：固定查表，红 17 / 蓝 16 / 绿 16

### 8. 今日幸运号码

复用同一套起卦结果，把七个卦数拼成一个七位数取模：

```text
seed  = u·10⁶ + l·10⁵ + m·10⁴ + hu·10³ + hl·10² + bu·10 + bl
lucky = seed mod 49 + 1
```

### 9. 一期完整示例（2026-11-06 05:30 北京时间，实跑一次）

```text
农历        丙午年 九月廿八        年支 yz = 7（午）      时辰 sc = 4（卯）
base        7 + 9 + 28 + 16 = 60
本卦        上 60%8 = 4 震    下 (60+4)%8 = 0→8 坤    动 (64)%6 = 4
六爻        下卦 000 + 上卦 100  →  雷地豫
互卦        上互 2·3·4 爻 = 6 坎   下互 3·4·5 爻 = 7 艮   →  水山蹇
变卦        第 4 爻翻转 → 上 8 坤 / 下 8 坤             →  坤为地
卦数序列    [4, 8, 4, 6, 7, 8, 8]
同余类      4:4,12,20,28,36,44   8:8,16,24,32,40,48   4   6:6,14,22,30,38,46   7:7,15,23,31,39,47   8   8
抽中号码    20, 16, 4, 22, 23, 32  |  特码 48        （7 个互异）
今日幸运    seed = 4 846 788 → mod 49 = 2 → 号码 3
```

同一天的不同时辰，`base` 不变而上卦恒为 4 震，下卦与动爻轮转，骨架整体换一遍：

| 北京时间 | 时辰 | 下卦 | 动爻 | 互卦（上/下） | 变卦（上/下） | 类序列 |
|---|---|---|---|---|---|---|
| 05:30 | 卯 4 | 8 坤 | 4 | 6 坎 / 7 艮 | 8 / 8 | 4,8,4,6,7,8,8 |
| 07:30 | 辰 5 | 1 乾 | 5 | 2 兑 / 1 乾 | 2 / 1 | 4,1,5,2,1,2,1 |
| 09:30 | 巳 6 | 2 兑 | 6 | 6 坎 / 3 离 | 3 / 2 | 4,2,6,6,3,3,2 |
| 13:30 | 未 8 | 4 震 | 2 | 6 坎 / 7 艮 | 4 / 2 | 4,4,2,6,7,4,2 |

### 10. 随机性边界

- **确定部分**：七个卦数、七个同余类、生肖、波色 —— 全部由「农历年支 + 月 + 日 + 时辰」唯一确定，同一时辰里重开多少次骨架都一样。
- **随机部分**：每类里挑哪个号，走 `Math.random()`。
- **分布有偏**：类 1 有 7 个成员，其余类 6 个，所以 `1/9/17/…/49` 被抽中的概率是 `1/7`，其他号是 `1/6`。
- **一次生成、动画回放**：`genNums()` 在第一个球开始滚之前就把 7 个号全部算好，滚动只是表演，中途不会改结果。
- 结论：对真实开奖既不可预测（类内随机），也不等价（骨架与日期强相关、分布不均），纯娱乐演示。

## 开奖动画与音效时序

- 参数：`CFG = { NORMAL: 6, MIN: 1, MAX: 49, ROLL: 50, GAP: 250 }`
- 每球：40 帧快滚（`2000 / ROLL`，250 ms/帧）→ 5 帧减速（120 / 160 / 200 / 260 / 340 ms）→ 落定并爆粒子
- 球间停顿 250 ms，7 个球合计约 80 秒
- 滚动帧序列生成时就排除「已开号码」和「本球终值」，且不与前一帧重复
- 音效：滚动为 880–1080 Hz 正弦（50 ms 指数衰减）；落球为 C 大调琶音（523.25 / 659.25 / 783.99 / 1046.5 Hz）；特码升八度五音（1046.5 → 2637.02 Hz，三角波）
- BGM 解码后循环播放，`onended` 里重新起播，避免一次播完就静音

## 快速开始

```bash
git clone https://github.com/ab123666/MarkSix.git
cd MarkSix
python -m http.server 8000
```

打开 <http://localhost:8000>，或直接双击 `index.html`。

## 使用

1. 点「开始开奖」，7 个球依次滚出，特码排在最后。
2. 每期开完自动写入历史，左侧卡片显示日期、农历与当期幸运号码。
3. 「重置」清空盘面回到初始态；「清空历史」删除 localStorage 里的记录。

## 目录结构

```text
index.html   单文件：页面结构 + 样式 + 内联 BGM/图标 + 取数逻辑（约 440 KB）
```

## 说明与限制

- 与任何真实彩票开奖无关，纯娱乐演示；号码生成不具备预测能力。
- 源码里还留着一张 `(月 × 日 × 星期) → 1–49` 的静态 `lucky` 表，当前版本已改用 `todayLucky()` 的卦数取模方案，这张表是早期算法残留、未参与计算。
- 一期约 80 秒，想快可以调小 `CFG.ROLL`（帧数 `2000 / ROLL` 会同步变多）。
- 农历表覆盖 1900–2100，超出范围会算错。
- 历史只存在本机浏览器，换设备不会同步。
- 音效需要一次用户交互才能启动（浏览器自动播放策略）。
