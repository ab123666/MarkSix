# MarkSix

六合彩风格「琼花开奖器」：**6 个正码 + 1 个特码（1–49）→ 逐球滚动开奖 → 生肖 / 波色实时推算 → 历史记录本地留存**。

单文件 HTML，BGM、图标、音效全部内联，断网也能跑。

## 特性

- **号码结构**：`CFG.NORMAL = 6` 个正码 + 1 个特码，号码范围 `1 ~ 49`。
- **波色**：红波 17 个、蓝波 16 个、绿波 16 个，按六合彩标准分色（`RED` / `BLUE` 两个 Set，其余归绿）。
- **生肖**：`zodiac(n) = ZOD[(yi − (n − 1)) mod 12]`，基准 `yi` 由当前年份推出，跨年自动换。
- **开奖动画**：每球先 40 帧快滚（`2000 / ROLL = 40`，250 ms/帧），再 5 帧减速（120 → 340 ms），落定后爆粒子；球与球之间间隔 250 ms。
- **不重复**：滚动序列在生成阶段就排除「已开出的号码」和「本球最终号码」，不会出现闪回已知数字的破音。
- **号码池生成**：`genNums()` 用农历年支、月、日、时辰换来三爻先天八卦 → 卦数序列 → 按步长 8（与 49 内的同余类对应）取样，每卦随机取一个未用号，凑出 6 + 1。
- **音效**：全部 Web Audio 实时合成 —— 滚动时的 880–1080 Hz 正弦短音、落球的四音和弦、特码高八度的三角波琶音，零音频文件依赖。
- **BGM**：base64 内联 MP3 循环播放，首次点击后才启动（绕开自动播放限制），并用增益 `1e-5` 的静音振荡器保活 `AudioContext`。
- **历史**：`localStorage['lucky_history']`，最多保留 20 期，带 `M/D HH:mm` 时间戳，可一键清空。
- **今日卡**：公历 + 农历（内置 `LUNAR` 压缩表）双显示；「今时幸运号码」按 `月 × 日 × 星期` 的乘积排序映射到 1–49，每两小时（一个时辰）自动刷新一次。
- **离线可用**：唯一外链是 Google Fonts 的「马善政」毛笔字体，断网时回退系统字体，功能不受影响。

## 快速开始

```bash
git clone https://github.com/ab123666/MarkSix.git
cd MarkSix
python -m http.server 8000
```

打开 <http://localhost:8000>，或直接双击 `index.html`。

## 使用

1. 点「开始开奖」，7 个球依次滚出，特码排在最后。
2. 每期开完自动写入历史，左侧卡片显示本期日期、农历与当期幸运号码。
3. 「重置」清空盘面回到初始态；「清空历史」删除 localStorage 里的记录。

## 目录结构

```text
index.html   单文件：页面结构 + 样式 + 内联 BGM/图标 + 开奖逻辑（约 440 KB）
```

## 说明与限制

- 与任何真实彩票开奖无关：号码由 `Math.random` 加卦象映射生成，不是加密随机，也不具备预测能力，纯娱乐演示。
- 历史只存在本机浏览器，换设备不会同步。
- 首次开奖时 BGM 需要先异步解码 base64 音频，可能有极短延迟；音效本身不受影响。
- 开奖过程中「重置 / 清空历史」被禁用，避免动画与状态互相踩踏。
